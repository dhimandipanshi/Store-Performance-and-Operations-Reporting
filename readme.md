# Fictional Retail Reporting and Analytics Project

This project is fictional and uses entirely synthetic data.

It is inspired by a Reporting and Analytics Specialist job description.
It does not represent real TJX Canada data, stores, employees, systems,
performance figures, or proprietary information.

## Purpose

This project demonstrates:

- Star-schema data modeling
- Power BI reporting
- KPI analysis
- Data-quality monitoring
- Reporting activity tracking
- Automation monitoring
- Regional business analysis
